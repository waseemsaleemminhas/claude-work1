# Ironclad Tech Ledger — installing it on your phone

Needs Android 7 or newer. Takes about two minutes.

**1. Download it.** Tap the link, then the download arrow.

**2. Tap the downloaded file.** The phone will say it is not allowed to install
apps from this source. Tap **Settings** on that message, turn the switch on,
then press back — it carries on where it left off.

**3. If it says "unsafe app blocked"**, tap **More details → Install anyway**.
That warning only means the app did not come from the Play Store. It is ours.

**4. Open it and put your name in.** That name goes on every entry you make.

**5. Settings (bottom right), "The shared book":** paste the web app link, and
the access code you were given. Your code is yours — don't pass it on. Then tap
**Sync now**. It should say it took some entries back.

**6. One last thing, so it keeps up on its own.** Settings → Apps → Ironclad
Tech Ledger → Battery → **Unrestricted**. Without it the phone will throttle the
half-hourly catch-up, and you'll only see other people's entries when you open
the app.

## Using it

- **−** for money out, **+** for money in. It asks which day first, on today —
  tap **Cancel** to keep today, or pick the day it actually happened.
- Then a category, the amount on the keypad, **Add**.
- It works with no signal. Entries sit on the phone and go up by themselves when
  you next have one.
- Hold the home screen → Widgets → Ironclad Tech Ledger, for entering a cost
  without opening the app.

## Updating

Sync first, then install the new file over the top. Nothing is lost and you keep
your name and settings.
